# Signal to Story — V4 homepage prototype

This is an isolated, un-deployed homepage prototype for review. It does not replace the live Fold V3 site.

## Run

From the project root:

```bash
node v4/serve.js
```

Open <http://127.0.0.1:4182/>.

## Smoke test

Keep the server running in another terminal, then run:

```bash
node v4/test.js
```

## What to review

- The opening hero sequence: guide line, paper mat, statement, and one live signal phrase.
- The left chapter rail and its scroll-linked progress.
- The Working Surface project stage. Click a project or focus a project and use the arrow keys.
- The transition between project image, discipline, status, summary, and source line.
- The three-step visual walkthrough in the Method / Story chapter.
- The closing signal and honest contact disclosure.

## Boundary

This prototype uses the supplied actual project assets, but it is not deployed and it does not implement the four production case-study routes. That work waits for homepage approval.
