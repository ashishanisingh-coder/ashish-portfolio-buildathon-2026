## Routes delivered

- `/v5.1/projects/india/` — India in Transition
- `/v5.1/projects/rotavirus/` — Rotavirus
- `/v5.1/projects/uno/` — Simulanis Uno

All routes share a flat, sharp editorial system:

- fixed dark project header with back-to-work link, current project name and continuous reading progress;
- large sans-led hero with real project imagery and truthful captions;
- pinned-feeling sequence with a scroll index, active beat and smooth 2D image wipes;
- closing statement with previous, return and next navigation;
- no cards, gradients, glow, rotation, 3D treatment or hard offset shadows.

## Asset truth

The routes use only assets already present under `assets/actual/`.

### India in Transition

Uses the supplied cover, big picture, geography map, synthesis montage, wide/tall work-system views and closing bridge. The sequence is editorial rather than a card grid: broad picture → geography → synthesis → work system → closing bridge.

### Rotavirus

Uses the supplied cover, overview, tall slide archive, key takeaways and closing frame. The tall archive remains a narrow, inspectable source inside the flat image window; it is not stretched into a wide hero.

### Simulanis Uno

Uses only the supplied `261 × 2048` portrait case-study strip. The strip is kept narrow and scrollable as one continuous source. No extra interface screens or invented project imagery were created.

## Visual review pass

The route set was reviewed again at both target viewports. The strongest system decisions remain the fixed dark header, single focal image window, active sequence index and restrained orange signal line. One concrete issue was corrected: the Rotavirus source slides carried important text that was being cropped by generic cover treatment. Its hero and sequence slides now use truthful contain treatment, a landscape hero frame for the 16:9 source, and a shorter route-specific sequence window; the tall archive remains narrow and inspectable. India in Transition and Simulanis Uno retain their previous compositions.

Review outcome: **8.6/10**. The routes read clearly in the first viewport, the typography and grid are consistent, the asset treatment is source-faithful, and the motion stays flat and purposeful. The remaining intentional constraint is the narrow Simulanis Uno source strip; it is not widened or supplemented with invented imagery.

## Accessibility and safety

- Skip link targets `#main-content`.
- The route server allowlists only `india`, `rotavirus` and `uno`; unknown project slugs return `404`.
- Native links retain visible focus states.
- Active sequence beat exposes `aria-current="step"`.
- Non-active image panels are hidden from assistive technology.
- Reduced-motion mode disables sequence choreography and keeps the first beat visible.
- Route and asset paths are root-relative and reproducible.
- Final Playwright pass verified heading structure, image alt coverage, duplicate IDs, skip-link focus, `#story` navigation, reduced-motion state, active-beat `aria-current`, console errors and horizontal overflow at both viewports.
