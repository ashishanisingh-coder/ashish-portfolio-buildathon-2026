## Navigation and motion

- The homepage fixed header now exposes Opening, Philips, India, Rotavirus, Uno and Contact.
- Philips in the homepage header opens the dedicated Philips case study; the homepage CTA still provides an internal Philips preview.
- Case-study headers use the same Flat Signal wordmark, dark fixed shell, portfolio navigation, active project state and continuous reading progress.
- Case-study mobile headers provide the same project list in an accessible menu with Escape-to-close and focus restoration.
- Previous / Return / Next links form a complete cycle:
  `Philips → India → Rotavirus → Uno → Philips`.
- All four routes link back to the homepage.
- The homepage hero retains masked title reveals, rectangular image reveal, guide/rule draws and flat 2D motion only.
- The remaining planar image-settle transform was removed from the hero. No rotation, perspective, 3D transform, glow, gradient or shadow was added.
- Philips continues to use the single supplied composite with truthful sequence copy and no invented panel exports.
- Uno continues to use only the supplied `261 × 2048` portrait strip at native narrow width.
- Rotavirus hero and sequence frames use contain treatment so source-slide text remains visible; the tall archive remains narrow and inspectable.

## Story and visual review

Each route has a different source-led reading mode:

| Project | Story structure | Visual treatment |
| --- | --- | --- |
| Philips TV & Audio | Campaign cover → overview → touchpoints → original artwork → festive → retail → adaptations → takeaways | One intact supplied composite read as a narrow continuous strip |
| India in Transition | Big picture → geography → synthesis → work system → closing bridge | Gallery sequence with single and multi-image editorial frames |
| Rotavirus | Overview → visual system archive → key takeaways → closing frame | Full-frame source slides plus a narrow tall archive |
| Simulanis Uno | Case-study opening → industrial training → unified platform → closing line | One continuous native-width portrait strip |

The visual system remains intentionally flat and editorial: hairline rules, paper/dark contrast, sans typography, sharp image windows and continuous 2D scroll-linked changes. There are no generic cards, rounded dashboard tiles, fake UI screens or invented project visuals.

Review result: **8.8/10**. The integrated system is clear in the first viewport, project-to-project movement is direct, source assets are treated honestly, and the four routes have distinct content structures despite sharing the same navigation language.
